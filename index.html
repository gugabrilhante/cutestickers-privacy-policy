CuteStickers — Privacy Policy

🇧🇷 Português

Última atualização: Maio de 2026

O CuteStickers respeita sua privacidade. Este aplicativo permite descobrir imagens de cães e gatos, salvar imagens localmente e criar stickers para aplicativos compatíveis.

1. Público-alvo

O CuteStickers pode ser utilizado por adolescentes, adultos e crianças, com supervisão dos responsáveis quando aplicável.

2. Dados coletados

O aplicativo não coleta dados pessoais identificáveis como nome, e-mail, telefone ou localização.

3. Conteúdo online

O aplicativo utiliza APIs públicas para carregar imagens de animais. Buscamos utilizar apenas conteúdo apropriado para todas as idades.

4. Armazenamento local

O aplicativo pode armazenar arquivos localmente para:

  • Cache de imagens
  • Downloads feitos pelo usuário
  • Criação de stickers

5. Compartilhamento

Não vendemos, alugamos ou compartilhamos dados pessoais com terceiros.
