CuteStickers — Privacy Policy

Last updated: May 2026

🇧🇷 Português

1. Introdução

O CuteStickers respeita sua privacidade. Este aplicativo permite descobrir imagens e GIFs de cães e gatos, salvar conteúdo localmente e criar stickers para aplicativos compatíveis.

2. Público-alvo

O CuteStickers é destinado ao público geral e não foi desenvolvido especificamente para crianças menores de 13 anos.

3. Coleta de dados

O CuteStickers não coleta dados pessoais identificáveis. O aplicativo também não utiliza analytics, tracking ou SDKs de publicidade.

4. Serviços de terceiros

O aplicativo utiliza conteúdo fornecido por:

  • The Cat API
  • The Dog API

5. Permissões e armazenamento local

O aplicativo pode utilizar:

  • Acesso à internet para carregar imagens e GIFs
  • Armazenamento local para cache, downloads e criação de stickers

6. Compartilhamento de dados

O CuteStickers não vende, compartilha ou transfere dados pessoais.

7. Alterações nesta política

Esta política pode ser atualizada periodicamente.
